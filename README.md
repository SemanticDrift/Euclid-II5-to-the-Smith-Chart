# Euclid-II5-to-the-Smith-Chart
Euclid II.5 read as a lossless transmission line: the extents AD = a+b and DB = a-b are the sum and difference of the incident and reflected amplitudes. The Smith chart transformation sends their ratio to Γ = b/a exactly, and II.5 becomes the power balance. Verified against Smith’s 1939 worked example.
